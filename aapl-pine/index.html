AAPL Chart Levels — TradingView Pine Script

Overlay companion to the DPWD Market Temperature script · Not financial advice
Pine Script v6 · overlay=true
Before pasting: TradingView auto-inserts a default indicator("My Script") line. Delete it first, then paste the full code below — otherwise you'll get the "Your script has 2" error.
How to use
  1. Open AAPL on a daily chart.
  2. Pine Editor → paste the code below (after removing the default line) → Add to Chart. The MA20/50/200 lines and the key-level horizontal lines appear on the price pane.
  3. For the full post chart, also add the DPWD Market Temperature script as a separate pane (right-click the indicator → Move to → New pane below) and add the native Volume indicator.
  4. Levels are fixed from the post (344.57 52-week high, 330.81 20-day high, 316.47 MA50, 300.57 20-day low, 284.35 MA200). Edit the numbers if price moves.
//@version=6
// AAPL Chart Levels — overlays MA + key levels from the post chart.
// Companion to the DPWD Market Temperature script (add that one as a separate pane).
// Not financial advice — educational overlay.
indicator(title="AAPL Chart Levels", shorttitle="AAPL LV", overlay=true)

// ── Moving averages (mirror the report's daily MAs) ──
ma20  = ta.sma(close, 20)
ma50  = ta.sma(close, 50)
ma200 = ta.sma(close, 200)
plot(ma20,  "MA20",  color=color.new(color.orange, 0), linewidth=2)
plot(ma50,  "MA50",  color=color.new(color.blue,   0), linewidth=2)
plot(ma200, "MA200", color=color.new(color.lime,   0), linewidth=2)

// ── Horizontal key levels ────────────────────────────────────────────────
// Dashed, bright, THICK lines. hline() ignores linewidth and plot() can't dash,
// so we draw persistent lines once (var) with extend.both to span the chart.
// Keep colours/widths bright; edit the numbers if price moves.
f_level(lv, col, w) =>
    var line ln = line.new(bar_index, lv, bar_index, lv, xloc=xloc.bar_index, extend=extend.both, color=col, width=w, style=line.style_dashed)
    line.set_y1(ln, lv)
    line.set_y2(ln, lv)

f_level(344.57, color.red,    3)  // 52-week high — event failed to reclaim it
f_level(330.81, color.yellow, 2)  // 20-day high — near-term resistance
f_level(316.47, color.aqua,   2)  // MA50 — current pivot (price just below)
f_level(300.57, color.fuchsia, 2) // 20-day low — support shelf
f_level(284.35, color.purple, 2)  // MA200 — major bull/bear line
